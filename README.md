# powershell-branch-health-check
Automated diagnostic and health check script for Windows branch endpoints
PowerShell Script untuk Maintenance IT Cabang

Repositori ini saya buat untuk menyimpan skrip PowerShell yang saya pakai sehari-hari dalam merawat komputer dan sistem di kantor cabang.

Masalah yang Dihadapi: Sebagai satu-satunya orang IT di cabang, saya sering repot kalau harus mengecek kondisi komputer satu per satu, memeriksa layanan Windows yang mati, atau mengumpulkan data inventaris secara manual.

Solusi yang Dibuat (SystemHealthCheck.ps1): Saya menulis skrip sederhana ini untuk membantu tugas-tugas rutin tersebut. Fungsinya untuk:

Mengecek status jaringan dan komputer secara otomatis.
Memastikan layanan penting Windows berjalan normal.
Menyimpan log hasil pengecekan untuk memudahkan pencarian masalah (troubleshooting).
Skrip ini murni saya buat sendiri berdasarkan kebutuhan operasional di lapangan agar pekerjaan lebih cepat selesai dan meminimalkan gangguan pada sistem.
